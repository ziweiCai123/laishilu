# 《来时路 The Road Hither》游戏设计文档 GDD v2.0

> 2026-09 重构版。项目从"原型迭代"转向"成品标准生产"。
> 目标:一款让大部分人喜欢的宁静冒险,玩家能在其中看见自己成长的记录。

---

## 一、产品定义

- **一句话**:沿一条真实的路(大理→丽江→虎跳峡→香格里拉→梅里)向北行走,把散落的记忆拾回来,把成长的记录种下去,最后在日照金山里抵达。
- **平台**:PC(Godot 4.7 Forward+),后期 Web 导出;手柄支持在 M4。
- **时长**:单次完整流程 60–90 分钟;设计上支持无限重访(留灯、手账、周年)。
- **受众**:喜欢《光·遇》《Journey》《A Short Hike》的玩家;想给自己留记录的人。无年龄门槛。
- **三根情感支柱**:
  1. **宁静**——无失败、无敌人、无死亡、无倒计时;
  2. **回望**——记忆系统是玩法本体,不是收集品;
  3. **抵达**——成长必须被"看见":星图、结算信、金山的亮。

## 二、世界结构:五个段落,一条真实的路

| 段落 | 地名 | 主题 | 情感曲线 | 标志性瞬间 |
|---|---|---|---|---|
| 序章 | 风起 | 教学 | 平静出发 | 穿过木牌坊,风起 |
| 第一章 | 大理 · 风与花 | 下关风/上关花/洱海 | 明亮欢快 | 花海风口第一次长滑翔,掠过洱海 |
| 第二章 | 丽江 · 蓝月与灯火 | 蓝月谷/古城 | 好奇与温柔 | 梯级蓝池的水色;暮色里古城灯次第亮起 |
| 第三章 | 虎跳峡 · 雾峡 | 深谷/水声/雾 | **低谷**:沉重、迷雾、几乎无暖色 | 峡底抬头一线天;唯一暖光是一段记忆 |
| 第四章 | 香格里拉 · 高原与经幡 | 草甸/镜湖/经幡/寺影 | 辽阔与恢复 | 经幡阵在风里全部展开;湖面倒映雪山 |
| 终章 | 梅里 · 日照金山 | 夜攀/黎明 | 庄严、抵达 | **第一缕阳光点燃雪峰**,尾声结算「来时路之信」 |

- 地理逻辑 = 情感逻辑 = 海拔逻辑:一路向北,一路抬升,从花海到神山。
- 每章为**手工设计的独立空间**(白盒→美术),不再是程序化大碗。

## 三、核心循环

行走/滑翔/坐下 → 看见光柱与地标 → 拾起记忆(世界回血:雾薄、色暖、乐声部+) →
在信物点**写下/放入自己的记录** → 成长星图生长 → 终章一切汇合。

## 四、成长记录系统(差异化核心)

1. **记忆**(叙事层):每章 8–12 段,光柱引路;类型 whisper/photo/object。
2. **信物与手账**(玩家层):章节内设"信物点"(石座/灯台),互动后可用照片+一句话+日期**种下自己的时刻**;存档持久。
3. **成长星图**:每拾起/种下一段,星图亮一颗星;每章一个星座骨架,通关后合成完整星图;标题屏可回看。
4. **来时路之信**:终章生成一张可分享的结算图(走过的路、拾起的记忆、种下的时刻、步数、灯火、日期)。
5. **重访理由**:留灯(已有的 C 系统)、周年闪烁(v2)、不同时段进谷的光色差异。

## 五、玩家:光灵 + 飘巾

- 形象:无面光灵,踏光而行;**一条 Verlet 物理飘巾**——颜色随拾起的记忆变暖/变长,是"成长"的可见化。
- 移动:步行 4.6 m/s、跳跃、空中按住空格**滑翔**(9.5 m/s)、X 坐下;无奔跑键——散步是刻意的。
- **风口**(风元素):大理章的风口可以把玩家托升——滑翔教学与乐趣来源,每章至少一处地形风。
- 低谷章:移速沉、雾重、色彩褪(保留现有 heavy 机制,在雾峡强化)。
- 输入:键鼠先行,手柄 M4。

## 六、美术圣经

- **全局基调**:油画质感、暖纸金调(与个人主页同源);宁可不饱和,不可脏。
- **章节色盘**:
  1. 大理:苍山黛绿 + 洱海湖蓝 + 花田粉白 + 风的流动感
  2. 丽江:蓝月谷 tiffany 蓝 + 古城灯笼暖橙 + 玉龙雪白
  3. 虎跳:铁灰 + 雾青,几乎无暖色——**记忆的暖光是画面里唯一的暖**
  4. 香格里拉:高原金绿 + 经幡五色(蓝白红绿黄) + 湖镜天光
  5. 梅里:夜蓝 → 金山时刻的暖金爆发
- **UI「纸与金」设计系统**:暖纸底(0.957,0.937,0.902)+ 描金(0.659,0.529,0.31),细边框,衬线中文;所有界面(手账/星图/暂停/结算信)同一语言。
- 地形:程序化高度图 + **逐章手工调整**(整地、放置地标);材质逐章配色 + 细节纹理。

## 七、音频方向

- 每章一个**主题动机**(五声音阶体系),分层 stems 随行为交叉渐变。
- 虎跳章:音乐几乎静默,只留水声轰鸣与风——记忆拾起时的暖音是对比设计。
- 终章:全部动机在日照金山时刻汇合。
- 音效:脚步(已有草/雪/石,补:水、木、雪线风)、环境层(湖浪、经幡猎猎、古城人声远景)。

- 性能预算:1080p 中配 60fps;光源用 distance_fade;草/粒子分章预算。

## 九、里程碑

| 里程碑 | 内容 | 验收标准 |
|---|---|---|
| M0 | 本 GDD | 用户确认 |
| **M1 垂直切片** | **第一章·大理 完整品质**:光灵+飘巾控制器、手工关卡(花海/洱海/风口/地标/秘境)、章节色盘光照、主题音乐、手账+星图 v1、章尾定格瞬间 | 用户试玩后认为"这就是成品该有的样子" |
| M2 量产 | 二三四章按切片标准 | 每章过第六节 checklist |
| M3 终章 | 梅里夜攀+日照金山+结算信 | 金山瞬间打动用户 |
| M4 打磨 | 手柄、设置全量、优化、导出 | 可分享给朋友玩 |

**每章质量 checklist**:地标 ≥3 / 秘境 1 / 定格瞬间 1 / 记忆 8–12 / 音乐主题 1 / 天气或时辰变化 1 / 风口或独特机制 1。

## 十、明确不做

战斗、敌人、失败惩罚、多人、开放世界、体力条、内购。
